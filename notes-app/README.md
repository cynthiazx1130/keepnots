# 守心便签（ZNotes）

一个参考苹果备忘录设计的跨端便签应用：**手机 / 电脑浏览器均可使用**，数据保存在本机并通过**个人网盘（WebDAV）云同步**，每条备忘录都是一个**标准 Markdown 文件**，特定**文件夹可加密**（AES-256），还可把**本机任意文件夹设为实时镜像备份**。

纯静态、无需后端：`index.html + core.js + app.js + style.css`。

> 前身为「云便签」，v1.3 起更名为「守心便签」。数据格式与云端目录完全兼容；桌面版会自动沿用旧数据目录，升级无需迁移。
> v1.3 起云端目录调整为 `便签/`、`加密便签/`、`回收站便签/` 三个子文件夹；旧版（明文在根目录、密文在「安心便签/」）升级后的**首轮同步会自动迁移**到新结构，无需手动处理。

## 功能

- **苹果备忘录式界面**：桌面两栏——左侧文件夹树（便签直接嵌在各文件夹下，可展开收起，边栏宽度可拖拽调整），右侧编辑器；**手机单栏 + 左滑操作**，竖屏下默认显示便签列表，顶栏右上角为「设置 ⚙」、右上旁为「＋ 新建」，列表末尾有大号「＋ 新建便签」按钮（另有悬浮圆形新建键）；加密便签在列表中显示 🔒 符号（解锁后为开锁符号），点击弹出密码框、解锁后直接进入该便签；浅色 / 深色跟随系统
- **三种视图模式**（编辑器顶栏切换，跨便签记忆）：**富文本**——所见即所得编辑，加粗/标题/列表/图片直接以最终样子呈现并自动序列化回 Markdown 存储（支持中文输入法不跳光标，粘贴按纯文本插入）；**源码**——Markdown 语法编辑；**阅读**——渲染预览（清单可直接勾选）
- **排版（参考 Word 页面设置）**：¶ 面板对齐用图标组（左/居中/右/两端）；行距为段内自动换行行的行距（倍数 1.0–3.0，默认 1.0）；段距为回车分段后的段前段后间距（倍行高 0–4，默认 1.5），均为「− 输入框 +」步进器，可直输数字回车
- **快捷操作**：选中便签后按 Delete 移入最近删除（回收站中为彻底删除，需确认）；列表中拖拽便签到左侧文件夹即完成移动（加密文件夹需先解锁）；Shift+点击文件夹多选，底部操作栏批量删除（未解锁的加密文件夹自动跳过）
- **新建入口显眼**：桌面端侧栏顶部有「＋ 新建便签」主按钮（Ctrl+N 同效），手机端是悬浮圆形按钮
- **云同步（按需选择，自动完成）**：设置 → 云同步为三个选项卡——**坚果云**（桌面版内置直连，只填账号与授权密码即可，全程无需代理；网页版自动检测本地代理）、**其他同步**（下拉选择 WebDAV 服务器或 Google Drive，按所选方式只显示必填项）、**不同步**；自动 + 手动同步，冲突自动保留副本
- **账户（同步我的设置）**：注册后，本机全部设置（含网盘同步配置、主题）用「用户名 + 密码」AES-256 加密成账户档案——自动保存在你指定的文件夹并随网盘同步上传；换电脑时导入档案文件或直接登录（档案已随网盘到达）即可一键恢复，密码不保存在任何地方
- **自定义同步节奏**：设置 → 云同步可选三档预设频率，或切「自定义」自行设定停止输入后的上传延迟（5–600 秒）与最小同步间隔（0.5–240 分钟），按网络性能灵活调节；还可分别开关「打开时同步 / 网络恢复补传 / 切后台同步」
- **本地保存位置（主存储）**：首次启动引导或设置中选择一个本机文件夹后，所有便签以标准 `.md` 文件**实时保存在其中**（`便签\` 明文、`加密便签\` 密文+解锁器、`回收站便签\` 已删除）——文件夹就是存储本体，随时可用其他软件查看、编辑（外部修改会在下次启动时自动导入）；换电脑拷走文件夹即可恢复；应用内部数据库作为缓存双写兜底
- **Markdown 存储**：云端每个笔记是一个带 YAML frontmatter 的 `.md` 文件，用任何 Markdown 编辑器都能直接打开
- **文件夹加密（安心便签）**：对任意文件夹设置密码，其中所有备忘录以 AES-256-GCM 密文保存，查看 / 编辑需先解锁；密码不离开本机。设置 → 加密文件夹可集中管理（设置 / 更改 / 移除密码、解锁、立即锁定），侧栏右键文件夹同样有效。同步时加密笔记单独存放在网盘的**「加密便签」子文件夹**，解锁器同放其中（见下文）
- **便签编辑器**：源码/富文本/阅读三视图顶栏切换；「🔒 加密」按钮一键对便签所在文件夹设密/锁定/解锁；「⋯ 更多」菜单可置顶、编辑标签、移动、导出（手机端置顶/预览/导出收纳于此）
- **标签**：便签可打标签（逗号分隔，frontmatter `tags:` 字段随云同步跨设备），显示在列表行与编辑器日期行，搜索可命中标签
- **核对清单**：`- [ ]` 任务清单，预览模式下点击即可勾选（同苹果备忘录）
- **插入图片**：工具栏按钮 / 直接粘贴 / 拖拽图片到编辑器即可插入；插入的是**图片副本**（原图删除不影响便签显示），副本保存在 `attachments/` 目录并随网盘与本地保存位置同步；预览/阅读模式中点击图片可缩放、左/中/右对齐（调整直接回写 Markdown）；加密文件夹中的图片随文件夹密钥一并加密存储
- **简单排版**：工具栏「¶ 排版」可按便签设置对齐方式（左 / 居中 / 右 / 两端）、行距与段前段后间距，随 frontmatter 跨设备同步
- 置顶、搜索、最近删除（保留 30 天，**云端「回收站便签」目录同步保留，跨设备还原自动传播**）、导入 / 导出 Markdown、移动端添加到主屏幕（PWA）

**手动同步**：左下角同步状态条、状态条旁的 ⟳ 按钮、设置里的「立即同步」，三处点击都会立即同步（不受自动频率限制）；同步进行中按钮图标会旋转。

## 快速开始

### 1. 打开应用

任选一种：

- **本地打开**：直接双击 `index.html`（Chrome / Edge 下完整可用）
- **静态托管（推荐，手机使用必需）**：把整个文件夹部署到任意静态托管（GitHub Pages、Vercel、内网 nginx、`python -m http.server` 等），手机浏览器访问后「添加到主屏幕」即可像 App 一样使用

> 手机与电脑同步的前提是它们都能访问同一个应用页面（数据本身放在网盘，页面只是载体）。

### 1c. 安卓版（APK，兼容安卓 4.4+，适配老机型如锤子 T1）

`android/dist/ZNotes-1.3.0.apk`（同名 `守心便签-1.3.0.apk`）是标准的安卓安装包：拷到手机安装（需在系统设置里允许「未知来源」安装），桌面自动创建「守心便签」图标。

- **技术形态**：系统 WebView 壳（minSdk 19）+ 打包的网页应用；网页 JS 已用 Babel 转译为 **ES5** 并附带 core-js / fetch / regenerator / CSS 变量垫片，专门兼容老安卓的旧版 WebView（Chromium 30+ 即可运行）
- **云同步**：壳层放行了 file 源跨域（等效桌面版 webSecurity:false），预期可直连坚果云等 WebDAV；网页版要求的本地代理在手机上不存在，若直连失败（CORS 拦截）请换用支持跨域的 WebDAV 服务
- **老机型的能力边界**（取决于手机 WebView 版本）：
  - 安卓 4.4 内置 WebView（Chromium 33）：**加密文件夹不可用**（系统 WebView 无 WebCrypto API，应用会提示「当前环境不支持加密」），普通笔记的增删改查、搜索、Markdown、阅读/富文本/源码三视图均可正常使用；深浅色切换依赖 CSS 变量垫片，个别排版细节（flex 间距 gap、刘海安全区）可能有差异
  - 更新的系统 WebView（约 Chromium 55+，即安卓 7.x 刷机后）：全部功能可用
- **数据**：笔记存于应用私有目录的 IndexedDB，卸载即清空；换机恢复走网盘同步（云端是主副本）
- **从源码重新打包**：
  1. 首次准备：`.apk-tools/` 下解压三件套（JDK8 → `jdk8u504-b01/`，build-tools 28.0.3 → `bt/android-9/`，platform-28 → `platform/android-9/`；官方地址 dl.google.com 与 Adoptium，国内网络亦可直连）
  2. 打包命令：`node dev/build-apk.mjs`（自动完成 ES5 转译、assets 组装、aapt2/javac/d8/zipalign/apksigner 全流程；产物输出 `android/dist/`）
- **电脑上模拟手机调试（免装 APK）**：双击工程根目录的 `手机预览.bat`（或 `node dev/phone-preview.mjs`）——弹出 360×640 的 Edge 窗口，加载与 APK 完全一致的 ES5 产物，开启触屏模拟（鼠标点击=点按、拖动=滑动，可试左滑），改动网页源码自动重建并刷新；测试数据持久保存。关闭浏览器窗口即退出。
- 限制：桌面版/网页版的「本地保存位置」（File System Access）在安卓上不可用，安卓版以应用内数据库 + 网盘同步为存储；插入图片走系统文件选择器，粘贴/拖入不可用

### 1b. Windows 桌面版（推荐给不想折腾网盘跨域的用户）

`desktop/dist/守心便签 Setup 1.3.0.exe` 是标准安装程序：双击安装，桌面与开始菜单自动创建「守心便签」快捷方式。旧版「云便签」升级安装后自动沿用原数据目录，笔记与同步配置不丢。

- **免代理直连坚果云**：桌面版不受浏览器跨域限制，服务器地址直接填 `https://dav.jianguoyun.com/dav/`
- **打开即同步**：配置过一次后，每次打开软件自动同步，编辑过程中也实时同步
- 数据与配置保存在系统用户数据目录，升级重装不影响
- 从源码重新打包：`cd desktop && npm install && node ../dev/build-desktop.mjs`
- 限制：桌面版暂不支持 Google Drive 授权（谷歌要求 http(s) 网页环境）；手机端仍用网页版

### 2. 配置云同步

> **先看网盘能不能用**：纯网页应用要求网盘允许浏览器跨域访问（CORS）。
> - ❌ **坚果云**：服务器不返回跨域头，**浏览器无法直连**（实测 2026-09）。电脑上可配合一行命令的本地代理使用，见下文[「坚果云为什么连不上」](#坚果云为什么连不上跨域限制)
> - ✅ NextCloud / 群晖等自建 WebDAV：加 CORS 响应头即可（见常见问题）
> - ✅ Google Drive：应用原生支持，见下文第 3 步

#### 方式 A：坚果云（推荐，设置第一个选项卡）

1. 打开应用 → 侧边栏「设置」→ 云同步 → **坚果云**选项卡（默认）
2. 登录坚果云网页版 → 账户信息 → 安全选项 → 添加授权密码（**不是登录密码**）
3. 填写账户（注册邮箱）与授权密码 → 「保存」，完成
   - **桌面版**：内置直连坚果云，到这一步就结束了，全程不需要代理
   - **网页版**：浏览器无法直连坚果云，保存前需先在电脑上运行 `node dev/webdav-proxy.mjs`（或双击「启动坚果云代理.bat」），保存时软件会自动检测代理是否可用

#### 方式 B：其他同步方式（WebDAV 服务器 / Google Drive）

设置 → 云同步 → **其他同步**选项卡 → 在下拉框选择方式，界面只显示该方式必填的信息：

- **WebDAV 服务器**（NextCloud / 群晖 / Alist 等）：填服务器地址、账户、授权密码；远程目录默认 `ZNotes`
- **Google Drive**：填 OAuth 客户端 ID → 「授权并连接」（一次性准备步骤见下文）

选定后「测试连接」→「保存」，之后修改会自动同步，也可手动「立即同步」。

#### 方式 B-1：Google Drive 详细准备

谷歌不提供 WebDAV，接入需要走官方 OAuth 授权，因此要一次性完成以下准备（约 5 分钟）：

1. **前提**：应用必须通过 `http(s)` 访问（本地 `python -m http.server` 的 `http://localhost:8000` 即可，手机长期使用建议部署到 https 托管）。`file://` 直接双击打开无法使用 Google Drive
2. 打开 [Google Cloud 控制台](https://console.cloud.google.com/) → 新建项目（名称随意）
3. 「API 和服务 → 库」中启用 **Google Drive API**
4. 「API 和服务 → OAuth 同意屏幕」：类型选**外部**，填应用名称；创建后在「测试用户」中**添加你自己的 Google 账号**（否则无法授权）
5. 「API 和服务 → 凭据 → 创建凭据 → OAuth 客户端 ID」：类型选 **Web 应用**，然后：
   - 「已获授权的 JavaScript 来源」填应用页面地址，如 `http://localhost:8000`（含端口号，协议必须与实际访问一致）
   - 「已获授权的重定向 URI」填**同一个地址**
6. 复制得到的**客户端 ID**（形如 `xxxx.apps.googleusercontent.com`），回到应用：设置 → 云同步 → 选「Google Drive」→ 粘贴客户端 ID → 「授权并连接」→ 在弹出的谷歌页面中同意授权

授权说明：

- 应用只申请 `drive.file` 权限：**只能看到和修改它自己创建的文件**，你网盘里的其他文件它碰不到
- 笔记以 `.md` 文件保存在你 Google Drive 的 `ZNotes` 文件夹中（和 WebDAV 完全相同的格式），换用其他网盘或导出都不受影响
- 授权令牌只保存在本机浏览器；「断开授权」会撤销令牌，也可以随时在 [Google 账号 - 安全 - 第三方访问权限](https://myaccount.google.com/permissions) 里手动移除
- 首次授权谷歌可能提示「未经验证的应用」：这是你个人自用的必然状态，点「高级 → 前往某项目（不安全）」继续即可；前提是第 4 步已把自己加为测试用户
- iOS 上若弹出「此浏览器不安全」，请在 Safari 中打开页面再授权（不要在 App 内嵌浏览器中操作）

WebDAV 与 Google Drive 可随时在设置中切换；切换后首次同步会自动重新比对云端与本机（不会覆盖远端已有数据，冲突仍有副本保护）。

同步后网盘里的目录长这样：

```
ZNotes/
├── folders.json          # 文件夹结构（含加密文件夹的盐值/校验值，不含密码明文）
├── account.json          # 账户档案（已注册时；加密的配置备份，详见「账户」说明）
├── 安心便签-解锁器.html   # 离线解锁器（有加密文件夹时自动生成）
├── memo/                 # 软件里的「memo」文件夹（加密文件夹，文件为密文，文件名即标题）
│   ├── 银行卡-x1k2p3.md
│   └── 今天新鲜的加密便签-q8w5t1.md
├── 备忘录/               # 软件里的「备忘录」文件夹
│   ├── 欢迎使用守心便签-a3f2k1.md
│   └── 会议记录-9d2x8c.md
└── 最近删除/             # 软件里的「最近删除」（保留 30 天，彻底删除才从云端移除）

> 目录与软件中的文件夹一一对应：新建 / 改名 / 删除软件文件夹，网盘与本地保存位置的目录会自动跟随。
```

每个 `.md` 文件示例：

```markdown
---
zid: m1x9c2k4a7b8
title: 会议记录
folder: 工作
created: 2026-09-06T02:10:00.000Z
modified: 2026-09-06T03:24:00.000Z
pinned: false
encrypted: false
app: ZNotes/1.0
---

# 会议记录

- [ ] 确认排期
- **要点**：这是一个普通 Markdown 文件
```

加密笔记的正文是密文块（标题也加密），必须回到应用输密码查看：

```
<!-- 此笔记已加密，请在守心便签中输入密码查看 -->
-----BEGIN ZNOTE-----
iv: 8Jx0…
data: kE3f…
-----END ZNOTE-----
```

## 数据保存在哪里？

| 位置 | 内容 | 说明 |
|---|---|---|
| **本地保存位置（推荐，主存储）** | 你指定的文件夹：每个软件文件夹一个同名目录（明文/密文跟随软件），文件名即便签标题；`最近删除\` 存已删除项；`attachments\` 图片附件；`folders.json` 文件夹结构 | 实时写入的标准 Markdown，任何软件可打开；换电脑拷走文件夹即可恢复。首次启动会引导选择，设置里可随时更改 |
| 本机 IndexedDB（内部缓存，自动双写） | 全部数据（加密笔记为密文） | 离线可用、秒开；保存位置暂不可用时自动兜底，恢复授权后按文件夹对账 |
| 网盘（WebDAV / Google Drive） | `ZNotes/` 下每个软件文件夹一个同名目录；`最近删除/`；`attachments/` 图片附件；`folders.json`、`account.json`、解锁器在根目录 | 跨设备同步；明文笔记即普通 Markdown |

- 加密密钥由「文件夹密码 + 随机盐」经 PBKDF2（150,000 次迭代）派生，AES-256-GCM 加密；**密码不保存在任何地方，忘记无法恢复**
- 锁定状态只存在于内存：刷新页面 / 重启应用后自动回到锁定状态

## 安心便签：加密笔记的云端存放与离线解锁

加密笔记按其所属文件夹的目录存放，文件内容为密文，**文件名即标题**（标题缓存自解锁/编辑时刻）；解锁器放在网盘根目录：

```
ZNotes/
├── folders.json                     # 文件夹元数据（含加密文件夹的盐值与校验值，不含密码）
├── memo/                            # 加密文件夹「memo」：内容为密文，文件名即标题
│   ├── 安心便签-解锁器.html          # 离线解锁器（单文件网页，随同步自动更新，与密文同放）
│   ├── 银行卡-x1k2p3.md
│   └── 今天新鲜的加密便签-q8w5t1.md
├── 备忘录/
│   └── 会议记录-xxxx.md             # 明文笔记，任何 Markdown 编辑器可开
└── attachments/                     # 插入的图片附件（随网盘与本地保存位置同步）
```

**解锁器怎么用**：在任意电脑上从网盘打开（或先下载）加密文件夹目录下的 `安心便签-解锁器.html` → 把加密文件夹目录下的加密 `.md` 文件拖进页面（可多选）→ 输入该文件夹的密码 → 即可阅读，还能一键「存为明文 .md」。页面完全离线运行、不联网，关闭即自动上锁；也可直接双击本地打开（Chrome / Edge）。

> 说明：按你的要求，加密笔记的**文件名直接使用标题**（便于在文件管理器中识别）；此前「文件名不泄露标题」的设计已按此调整。从未解锁过的加密便签因拿不到标题，文件名以「备忘录-编号」占位，解锁一次后自动改为标题。加密文件夹中插入的图片附件同样以该文件夹密钥加密（`.zatt` 文件）。

**安全边界**：

- 解锁器内嵌的只有盐值（salt）与密钥校验值（verifier）——这两项本来就随 `folders.json` 存在网盘里；**密码本身绝不写入解锁器**。拿到全部文件的人仍需暴力破解密码才能看到内容（PBKDF2 15 万次迭代抬高成本）
- 修改文件夹密码后，下次同步会自动更新解锁器（换新盐值）；解除文件夹加密后解锁器自动撤下
- 忘记密码依然无法恢复，这是加密的设计而非缺陷

## 坚果云为什么连不上（跨域限制）

测试连接报「无法连接服务器（网络或 CORS 限制）：Failed to fetch」即是此原因。实测（2026-09）：`dav.jianguoyun.com` 对任何跨域请求都**不返回 CORS 响应头**（预检直接 401），因此手机/电脑**浏览器里的网页**都无法直连坚果云——这与账号、密码、授权密码都无关，原生 App（如官网客户端）不受此限制。三种解决办法：

**方案一：本地代理（电脑，一行命令）**

```bash
node dev/webdav-proxy.mjs        # 需装有 Node.js；默认监听 127.0.0.1:8080
```

应用「服务器地址」改填 `http://127.0.0.1:8080/dav/`，账户/密码照常填坚果云账号与授权密码。代理只做转发并补上跨域头，不缓存不记录任何内容。

**方案二：代理跑在 NAS / VPS 上（手机 + 电脑全平台）**

把 `dev/webdav-proxy.mjs` 放到一台手机也能访问的机器上运行（`node webdav-proxy.mjs 8080`），服务器地址填 `http://那台机器IP:8080/dav/`。若用 nginx 反代，参考：

```nginx
server {
    listen 443 ssl;
    server_name dav.example.com;          # 换成你的域名，并配置证书
    location / {
        proxy_pass https://dav.jianguoyun.com;
        proxy_set_header Host dav.jianguoyun.com;
        proxy_ssl_server_name on;
        if ($request_method = OPTIONS) {
            add_header Access-Control-Allow-Origin "*" always;
            add_header Access-Control-Allow-Methods "GET, PUT, DELETE, PROPFIND, MKCOL, OPTIONS, MOVE, HEAD" always;
            add_header Access-Control-Allow-Headers "Authorization, Content-Type, Depth, Overwrite, Destination" always;
            return 204;
        }
        add_header Access-Control-Allow-Origin "*" always;
        add_header Access-Control-Allow-Methods "GET, PUT, DELETE, PROPFIND, MKCOL, OPTIONS, MOVE, HEAD" always;
        add_header Access-Control-Allow-Headers "Authorization, Content-Type, Depth, Overwrite, Destination" always;
    }
}
```

**方案三：换云端**

- 应用原生支持 **Google Drive**（见上文方式 B-1）
- 自建 NextCloud / 群晖 WebDAV：按下面常见问题里的 nginx 配置加跨域头即可；Alist 若挂载坚果云，同样需确认其 WebDAV 端点开启了跨域

## 同步频率与坚果云限额

**内容安全与上传节奏是分开的**：输入约 0.6 秒后内容即写入本机 IndexedDB（与网络无关），同步失败也只影响「上传副本」，本机数据绝不丢失；恢复网络后自动补传。

上传节奏（设置 → 自动同步频率，可随时切换；「立即同步」和点底部同步状态条永远立即执行、不受限制）：

| 档位 | 停止输入后上传 | 自动同步最小间隔 | 半小时高强度写作约消耗 |
|---|---|---|---|
| 即时 | 10 秒 | 30 秒 | ≤180 个请求 |
| **标准（默认）** | 15 秒 | 60 秒 | ≤90 个请求 |
| 省流量 | 60 秒 | 5 分钟 | ≤18 个请求 |
| 自定义 | 5–600 秒自定 | 0.5–240 分钟自定 | 按所设数值 |

三档预设之外还有**自定义档**：网络慢、不稳定或想精细控制请求量时，可自行设定「停止输入后上传延迟」和「最小同步间隔」两个数值；「同步时机」里的打开时同步 / 网络恢复补传 / 切后台同步也可分别开关。

请求开销做了专项瘦身：空闲同步为 **2~6 个**枚举请求（根目录 + 各软件文件夹目录，无回收站内容时不枚举最近删除目录；未变化的 folders.json / account.json 按 etag 缓存免下载）；打开应用、网络恢复、切到后台仍会立即补传。点「立即同步」时本地保存位置也会一并刷新。

**坚果云免费版限额**：上传流量 1GB/月、下载 3GB/月（纯文字笔记远用不完）；WebDAV 请求 **600 次 / 30 分钟**（专业版 1500 次）。按默认标准档正常使用远低于上限；万一触发（HTTP 503/429），应用自动退避 30 分钟再重试，其余失败按 1→2→5→15→30 分钟指数退避，期间界面上会显示「约 X 分钟后自动重试」。

## 常见问题

**测试连接报「无法连接服务器（CORS 限制）」？**
网盘未允许浏览器跨域访问。坚果云不支持（见上一节）；自建 WebDAV（nginx/apache）需加 CORS 响应头，例如 nginx：

```nginx
add_header Access-Control-Allow-Origin "*" always;
add_header Access-Control-Allow-Methods "GET, PUT, DELETE, PROPFIND, MKCOL, OPTIONS, MOVE, HEAD" always;
add_header Access-Control-Allow-Headers "Authorization, Content-Type, Depth, Overwrite, Destination" always;
```

**两台设备同时改了同一条笔记？**
同步时较新的一方胜出，被覆盖的一方自动生成一条「冲突副本」，不会丢内容。

**删除的规则是什么？（以软件操作为准）**
- 在**软件里删除**便签 = 移入回收站（软件内「最近删除」+ 本地文件夹「回收站便签\」+ 网盘「回收站便签/」三处一致），保留 30 天；**彻底删除**才真正清除，并通过删除墓碑同步到所有设备；
- 在**网盘网页上误删**文件：不影响本机，下次同步时软件自动把副本补传回网盘；
- 在**本地文件夹里误删** .md 文件：同样自动补写回来；
- 外部对 .md 的修改会在下次启动时自动导入；多处同时修改以最新的修改时间为主，败者保留冲突副本。
- 一句话：**删除必须通过软件完成，软件之外的任何删除都会被自动修复。**

**能完全离开这个应用使用数据吗？**
可以。明文笔记就是保存位置和网盘里的普通 `.md` 文件；应用内也可「导出全部笔记」为 Markdown（设置 → 数据）。

**本地保存位置和云同步什么关系？**
互相独立、互不影响。保存位置的文件夹是**存储本体**（随时可看可拷，外部修改会自动导入），网盘是跨设备同步通道；内部数据库双写兜底——任何一层出问题，其余副本都在。

**iOS 上怎么像 App 一样用？**
Safari 打开托管的地址 → 分享 →「添加到主屏幕」。
